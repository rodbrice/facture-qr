## 3. Fresh clone and Docker Compose

The branch was cloned into a new, empty directory, and only the commands of the README's *Quick start* were used. Port 8080 was already taken by another service on this computer, so the variable the README gives for that case was set; the CI job runs the demo on the default port 8080. The base images (`node:22-slim`, the .NET 10 SDK and ASP.NET Core runtime images, `postgres:17-alpine`) were already on the computer, and the build cache had been emptied: the build and start took 45 seconds.

```sh
git clone --branch fm/facture-qr-b4 <repository> facture-qr
cd facture-qr
FACTUREQR_PORT=8088 docker compose up --build --detach
```

## 4. Security tooling

- **CodeQL** (`.github/workflows/codeql.yml`): C# with the solution built (`build-mode: manual`) and JavaScript/TypeScript (`build-mode: none`), on pushes to `main`, pull requests and every Monday. The repository's CodeQL default setup is not enabled, so this workflow is the only configuration. Results appear under *Security → Code scanning* once the workflow has run on `main`.
- **Dependabot** (`.github/dependabot.yml`): weekly version updates for NuGet (`/`), npm (`/web`), GitHub Actions (`/`), the Dockerfile (`docker`) and the PostgreSQL image of `docker-compose.yml` (`docker-compose`); minor and patch updates of one ecosystem are grouped.
- **Repository settings, read on 26 November 2026, not changed by this unit:** secret scanning and push protection are enabled; Dependabot alerts, Dependabot security updates and private vulnerability reporting are disabled. Turning them on is a choice for the owner of the repository, in *Settings → Code security*.
- **SonarQube Cloud** is not part of this unit: it needs a SonarQube Cloud account and organisation linked to the repository, which do not exist yet. The other checks of the quality baseline (warnings as errors, .NET analyzers at `latest-recommended`, formatting, oxlint, CodeQL) run in CI.
- **Threat model:** README, section *Security*. Writing it found that `POST /invoices/{id}/issue` and `POST /invoices/{id}/mark-paid` accept an empty body, which a page of another site could send without a CORS preflight, and that the API answered any host name (DNS rebinding). Both are closed by ADR-0007.

## 6. Release notes of v0.1.0

The tag `v0.1.0` and the GitHub release are created on `main` after this unit is merged. The text below is the proposed release description, condensed from the `0.1.0` entry of [`CHANGELOG.md`](../../CHANGELOG.md):

> The first release: invoices in CHF with a Swiss QR-bill, for one person on one computer. The QR-bills pass the library's validation, a round trip through the decoder and an independent QR decoder; their validation in the SIX portal is still pending. There is no authentication: the application must not be exposed on a network.
>
> - QR-bill core library: Swiss and Liechtenstein IBAN and QR-IBAN, structured addresses, QR reference and Creditor Reference, the payment part with receipt as PDF or PNG with French headings.
> - Invoice model and storage: customers, invoices in CHF with their lines, draft → issued → paid, overdue derived from the due date, yearly numbering unique and without gaps under concurrency, PostgreSQL with EF Core migrations.
> - HTTP API: customers, drafts, issuing, payment, the invoice as an A4 PDF in French with its QR-bill, errors as ProblemDetails, JSON logs without personal data, OpenAPI.
> - Front end in French (React, TypeScript), served by the API.
> - Docker Compose demo: `docker compose up` gives the application on `127.0.0.1:8080` with synthetic data in every state.
> - Protections of the local API: changes from another site refused, only local host names answered.
> - Tests and CI: unit, storage and API tests against PostgreSQL, the invoice PDF's QR code read back by an independent decoder, Vitest, a Playwright end-to-end test, the Docker Compose demo, CodeQL and Dependabot.
>
> Quick start: `git clone https://github.com/rodbrice/facture-qr.git && cd facture-qr && docker compose up --build`, then open http://localhost:8080. Next: camt.054 import and automatic reconciliation of payments (v0.2).
